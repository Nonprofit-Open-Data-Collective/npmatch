# SAM public extract column layout

<div class="ref-description section level2">

order, so the headerless pipe-delimited `.dat` can be named.

</div>

<div class="section level2">

## Usage

<div class="sourceCode">

``` r
np_sam_layout()
```

</div>

</div>
