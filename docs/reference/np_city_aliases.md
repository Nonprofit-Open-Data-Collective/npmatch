# Common city aliases

<div class="ref-description section level2">

Whole-name city aliases mapped to a canonical form, used by
`np_clean_geo()`. Extend or replace with your own named character vector
(`"VARIANT" = "CANONICAL"`, uppercase).

</div>

<div class="section level2">

## Usage

<div class="sourceCode">

``` r
np_city_aliases()
```

</div>

</div>

<div class="section level2">

## Value

A named character vector.

</div>
