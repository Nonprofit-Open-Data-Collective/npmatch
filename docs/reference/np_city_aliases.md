# Common city aliases

Whole-name city aliases mapped to a canonical form, used by
[`np_clean_geo()`](https://nonprofit-open-data-collective.github.io/npmatch/reference/np_clean_geo.md).
Extend or replace with your own named character vector
(`"VARIANT" = "CANONICAL"`, uppercase).

## Usage

``` r
np_city_aliases()
```

## Value

A named character vector.
