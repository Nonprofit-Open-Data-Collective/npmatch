The first tagged release of **npmatch**, a record-linkage package that matches nonprofit records (an organization name plus whatever address detail is available) to the IRS Business Master File when no EIN is available.

v0 pins the code behind the combined 2025NOV + 2026MAY SAM-to-BMF crosswalk, so that crosswalk can be reproduced and cited against a fixed version.

## Install

```r
remotes::install_github("Nonprofit-Open-Data-Collective/npmatch@v0.1.0")
```

## Results of the pinned run

Of 175,053 SAM nonprofit registrants, **141,420 (80.8%)** are matched to a BMF EIN:

| matched by | matches | share of matches |
|---|---|---|
| stage 1 — probabilistic cascade | 121,972 | 86.2% |
| stage 2 — LLM adjudication of MAYBEs | 12,443 | 8.8% |
| stage 3 — LLM research of NOs | 7,005 | 5.0% |

Of the 33,633 unmatched registrants, stage-3 research found 12,892 are not nonprofits, 18,770 are nonprofits absent from this BMF vintage, and 1,971 could not be determined.

## What's included

- **Matching engine:** normalization → IDF-weighted progressive blocking → comparison → hierarchical scoring → do-not-match veto rules → YES / MAYBE / NO tiering (`np_cascade()`, `np_match()`).
- **Run projects:** one directory per run, driven stage by stage with `np_stage1_run()`, `np_stage2_run()`, `np_stage3_run()` and `np_final_run()`, which share a single outcome schema.
- **Review and training:** review frames, LLM prompts, a static HTML review report, model benchmarking, and a bundled hand-labeled benchmark of 1,502 organizations.
- **Documentation:** the pkgdown site with *Workflow*, *Reviewer guide*, *Candidate evaluation frame*, *Training dataset* and *Building a classifier* articles; plus the reviewer workbook builds in `dev/review-workbooks/`.

## Known issues

- 3,189 of the 4,925 stage-3 matches were never generated by stage-1 blocking; 1,507 more were scored but missed the shortlist and 229 were hard-vetoed.
- Name similarity is word-order sensitive; the order-insensitive recovery only runs when the address already matches.
- 5,226 registrants had every stage-1 pair hard-vetoed.
- 126 rows in the combined evaluation frame are `stage3_research` / `NO_MATCH` with an EIN but a blank `final_ein`.
