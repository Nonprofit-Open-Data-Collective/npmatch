# npmatch run: {{run_id}}

Created {{date}}.

One directory per matching run. Inputs at `00_*`, one folder per stage, and a
rollup in `04_final`. Every stage folder holds the same three subdirectories —
`batches/` (sharded work), `interim/` (expensive but not deliverable), `logs/` —
plus a `README.md`, a stats report, and its primary outputs.

## Running it

```r
library(npmatch)
np_project_use("{{run_id}}")   # point the session here
np_project_status()            # what has run, what it produced
```

Stages are optional and independent. A stage that never runs simply leaves its
outputs absent; `np_project_status()` reports it as *not run*, not as an error.

`RUN-STATUS.md` at this level is regenerated by `np_project_status()` and is
always a fresh scan of the directory — never a stored record that can drift.
